# Merchant OS Sales Page V1

High-fidelity, responsive customer-facing storefront prototype.

## Run locally

Open `index.html` directly in a browser, or serve the `web/sales` directory with any static HTTP server.

## Design principles
- Arabic RTL and mobile-first.
- Customer-facing storefront is separate from merchant operations.
- Personalized products are a first-class UI concept.
- WhatsApp is presented as support/follow-up, not the system of record.
- No backend or secrets are included in this prototype.

## Next integration stage
Connect product catalog, customer-interest events, targeted offers, order creation, and WhatsApp confirmation through Merchant OS APIs after the first experiment is complete.
